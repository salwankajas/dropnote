# Security policy

Dropnote is a prototype and is not recommended for production use with real user data, private resources, or durable accounts.

## Reporting a vulnerability

Please do not report vulnerabilities in a public issue. Once this project is published on GitHub, use the repository's **Report a vulnerability** feature (private vulnerability reporting / GitHub Security Advisories). Include affected versions, reproduction steps, and impact; avoid including real credentials or personal data.

If private vulnerability reporting is not enabled on the repository, contact the repository maintainers privately before disclosing details publicly. Maintainers should enable GitHub private vulnerability reporting before inviting public use.

## Supported versions

Only the latest version on the default branch is currently supported. There is no production SLA or guaranteed response time.
